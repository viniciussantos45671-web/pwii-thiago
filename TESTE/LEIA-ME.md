# CRUD de Funcionários (Node.js + Express + MySQL)

## Estrutura
TESTE/
├── banco.sql
├── index.html
├── script.js
├── style.css
└── backend/
    ├── package.json
    └── server.js

## Como executar
1. Inicie o MySQL (XAMPP/Workbench) e execute `banco.sql` na aba SQL.
2. No terminal:  cd backend  →  npm install  →  npm start
3. Abra `index.html` no navegador (ou com Live Server do VS Code).
